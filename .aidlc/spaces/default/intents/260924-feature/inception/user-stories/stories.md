# User Stories

US1.1: As a Customer, I want to browse the product catalog so that I can find shoes I'm interested in.
AC1.1.1: The catalog page loads successfully.
AC1.1.2: Products are displayed with images, names, and prices.
AC1.1.3: Products can be filtered by category.
AC1.1.4: Products can be sorted by price.

US1.2: As a Customer, I want to view product details so that I can learn more about a specific shoe.
AC1.2.1: The product detail page loads with full product information.
AC1.2.2: Images are displayed in a gallery format.
AC1.2.3: Available sizes and colors are shown.
AC1.2.4: Related products are suggested.

US1.3: As a Customer, I want to add a product to my cart so that I can purchase it later.
AC1.3.1: The "Add to cart" button is available on the product detail page.
AC1.3.2: The cart count updates when a product is added.
AC1.3.3: The cart modal shows the added product with options to adjust quantity.
AC1.3.4: The cart can be saved for later if the user leaves the page.

US1.4: As a Customer, I want to proceed to checkout so that I can complete my purchase.
AC1.4.1: The checkout button is available in the cart.
AC1.4.2: Shipping address fields are displayed.
AC1.4.3: Payment method options are presented.
AC1.4.4: The order summary is shown before submission.

US1.5: As a Customer, I want to create an account or log in so that I can save preferences and view order history.
AC1.5.1: The login form accepts email and password.
AC1.5.2: A new account can be created with name, email, and password.
AC1.5.3: The user is redirected to the original page after login.
AC1.5.4: Password reset functionality is available.

US1.6: As a Customer, I want to enter shipping information so that the order can be delivered.
AC1.6.1: Shipping address form validates required fields.
AC1.6.2: Available shipping methods are displayed with costs.
AC1.6.3: The user can select a shipping method.

US1.7: As a Customer, I want to select a payment method so that the order can be paid for.
AC1.7.1: Credit/debit card payment options are available.
AC1.7.2: Secure payment field validation is performed.
AC1.7.3: Alternative payment methods (e.g., PayPal) are offered.

US1.8: As a Customer, I want to receive an order confirmation so that I have a record of my purchase.
AC1.8.1: Order confirmation page is displayed after successful purchase.
AC1.8.2: Order confirmation email is sent.
AC1.8.3: Order number is displayed and can be referenced.
AC1.8.4: Estimated delivery date is provided.

US1.9: As a Customer, I want to view my order history so that I can track previous purchases.
AC1.9.1: The order history page lists all previous orders.
AC1.9.2: Each order shows the order number, date, and total amount.
AC1.9.3: The status of each order (processing, shipped, delivered) is visible.
AC1.9.4: Details of each order can be expanded.

US1.10: As a Customer, I want to filter products by category so that I can find shoes for a specific purpose.
AC1.10.1: Category filter options are displayed.
AC1.10.2: Products are filtered in real-time when a category is selected.
AC1.10.3: The filter can be cleared to show all products.
